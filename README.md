# AlwaysCursor

Mac のカーソルの上に、自前の大きなカーソルを重ねて描くメニューバー常駐アプリ。
本物のカーソルが隠れたり形を変えたりしても、**カーソルを見失うことがなくなります**。

## なぜ作ったか

Sunshine と Moonlight を使って Mac をリモート操作していたときのことです。
テキスト入力欄にカーソルを入れると、Mac はカーソルを I ビームに変えたり、アプリによっては非表示にしたりします。手元の画面では大した問題ではないのですが、リモート越しだとこれで**カーソルが完全に行方不明**になりました。

そこで、本物のカーソルの位置に、常に見た目の変わらない自前のカーソルを重ねて描くアプリを作りました。本物のカーソルに何が起きても、自前のカーソルはそこに居続けます。

リモート操作に限らず、「カーソルどこ行った？」を無くしたい人にもどうぞ。

## 特徴

- 本物のカーソルの上に、常に最前面で自前カーソル（矢印／丸）を描画。クリックなどは素通りするので操作の邪魔をしません
- 形ごとに設定を保持： 大きさ（0.3〜4.0倍）、輪郭と本体の色と有無、輪郭の太さ、ぼかし、不透明度
- 追従の調整： 動きの先読み（0〜40ms）と「なめらかさ」で、リモート越しでも遅れて見えにくくできます
- ディスプレイのリフレッシュレートに同期して追従（最大120Hz）。止まっている間は休止するので、余計な電力は使いません
- **Command キーを単独で押すと波紋**が出て、カーソルの場所を知らせます（色と大きさは変更可能）
- 設定を JSON ファイルに書き出し／読み込みできます
- ログイン時の自動起動に対応
- メニューバー常駐型で、Dock には出ません

## 動作環境

- macOS 13 以降

## ダウンロードと使い方

1. [Releases](https://github.com/riryo3/AlwaysCursor/releases) から `AlwaysCursor.app.zip` をダウンロードして解凍
2. `AlwaysCursor.app` をアプリケーションフォルダに移して起動
   - 未署名のアプリなので、初回は右クリック（または Control+クリック）→「開く」で起動してください
3. メニューバーにカーソルのアイコンが出ます
   - 「矢印でカーソルを覆う」： 表示のオン／オフ
   - 「設定…」（⌘,）: 形・色・追従などのカスタマイズ

## ビルド方法

ソースは Swift の単一ファイル（`main.swift`）です。Xcode のコマンドラインツールが入っていれば、ビルドスクリプトでアプリを組み立てられます。

```sh
sh build.sh
```

`AlwaysCursor.app` ができあがります（アイコンは `make_icon.swift` から生成します）。

## ファイル構成

- `main.swift` — 本体（これ1ファイル）
- `make_icon.swift` — アイコン生成用
- `Info.plist` — アプリの情報（macOS 13以降、メニューバー常駐）
- `build.sh` — ビルドスクリプト
- `AlwaysCursor.app` — ビルド済みアプリ
